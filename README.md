## Overview

Momora AI helps users remember what traditional search cannot.

Instead of searching through WhatsApp, emails, PDFs, screenshots, and notes separately, users simply ask a question in natural language.

Momora understands context, searches semantically using Retrieval-Augmented Generation (RAG), and provides accurate answers with references.

---

## Why Momora?

People lose information because it is scattered across multiple applications.

Momora unifies personal knowledge into one intelligent memory system that can:

- Remember conversations
- Organize academic information
- Understand documents
- Track important commitments
- Surface relevant information when needed

## Technology Stack

| Backend | FastAPI |
| AI | LangChain + Gemini |
| RAG | Chroma / pgvector |
| Database | PostgreSQL (Supabase) |
